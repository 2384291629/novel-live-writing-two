# novel-live-writing

写小说 / 网文用的**活人感总装** skill。单文件，零依赖。

让 AI 写的中文小说更像真人写的：过得了朱雀这类 AI 检测，同时文字有活人温度、不 OOC、有节奏。
不是「洗掉 AI 痕迹」，是从写作底层注入人味，再辅以分层自检纪律。

## 一份文件装齐

仓库里只有 `SKILL.md`。原项目的全部深度规则已压缩进这一份，**不需要 references/ 目录，不需要跑脚本**。复制粘贴即用。

## 特性

| | |
|---|---|
| **引号** | 只清半角直引号 `"`（U+0022）；原文用全角 `“ ”` 就保留，不擅自转换 |
| **破折号** | 清零，用逗号或句号代替 |
| **标点节奏** | 连贯叙述少用句号，适当用 ！？：且自然不突兀 |
| **改写方式** | 一句一句细改，骨架打散（段落结构、叙事顺序、信息组织都要动），不是换词汇 |
| **边界** | 保剧情、保人设、保格式，不 OOC，长度浮动 ±20% |
| **自检** | L1–L4 四层清单 + 误伤警告（看密度不看单次） |

## 三十条人味技法（节选）

- **私人细节**：「老相册」→「那本绿色封面的相册，扉页上用圆珠笔歪歪扭扭写着 2003.6.1」
- **情绪体感化**：「他很生气」→「他把杯子往桌上一墩，水洒了半杯，他没擦」
- **人性灰度**：全文不能出现 100% 纯良或 100% 纯恶的角色
- **恐惧记忆锚定**：恐怖场景至少一处感官信号与人物私人创伤绑定
- **干扰项注入**：不能让每条线索都在结尾精准回收，真人叙事像矿渣
- **句式情绪同步**：从句式形态能反推人物的情绪状态
- **主角必须犯错**：悬疑类主角必须犯至少 1 个推理错误
- **信息碎玻璃化**：真相打碎成 5–7 片散落在日常场景，禁止一次性直塞
- **电影桥段化**：镜头感、蒙太奇跳切、台词化对白（不强行、不 OOC）

完整 30 条在 `SKILL.md` 第 5 节。

## 安装

**方式一：作为 Agent Skill 安装**

把 `SKILL.md` 放进 skill 目录：

```
~/.claude/skills/novel-live-writing/SKILL.md
```

**方式二：让 agent 自己装**

```
帮我安装这个 skill：https://github.com/2384291629/novel-live-writing
```

**方式三：直接贴**

整份 `SKILL.md` 贴进任意对话，模型就能按规则改稿。无外部依赖。

## 用法

装好后，写小说正文、网文章节、人物对白、正文润色、去 AI 味改写时默认触发。也可以直接说：

```
用 novel-live-writing 帮我改这一章，过一下朱雀
```

输出包含：门检结论 → 四维诊断 → 改写亮点 → 前后对比 → 变更统计 → L1–L4 自检 → 残余风险 → 改写全文。

## 五个角色

按小说类型自动匹配，全文语气统一不串角色：

1. **悬疑探案** — 反「主角推理零失误」「伏笔零废料」「万能恐惧模板」
2. **言情** — 反「心动三件套」「男主完美症」「女主圣母症」
3. **玄幻/修仙** — 反「设定堆砌」「金手指空降」「升级流水线」
4. **都市/现实** — 反「生活感通用化」「感悟式结尾」
5. **通用小说**（兜底）— 通用九大病症

## 一个提醒

朱雀是概率分类器，不是事实判决。本 skill 不承诺检测器必过，只保证规则层清零 + 活人感到位。发布前建议用朱雀 / 腾讯云自测，按 350–2000 字切块。`SKILL.md` 的「残余风险」一节会诚实标注仍可能被命中的部分。
